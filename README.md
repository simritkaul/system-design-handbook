# System Design Handbook

This repository is a structured learning path for understanding modern system design, storage systems, and distributed architecture.

## Repository structure

- `System_Design_Handbook/1_Storage/` — storage fundamentals and database categories
  - `1_Storage_Fundamentals.md`
  - `2_Relational_Databases.md`
  - `3_No_SQL_Databases.md`
  - `4_Key_Value_Databases.md`
  - `5_Document_Databases.md`
  - `6_Wide_Column_Databases.md`
  - `7_Graph_Databases.md`
  - `8_Object_Storage.md`
  - `9_Search_Databases.md`
  - `10_Time_Series_Databases.md`
- `System_Design_Handbook/2_Distributed_Systems/` — distributed systems topics and architecture patterns

## What this repo covers

This handbook focuses on the core building blocks of large-scale systems:

- Storage models and their trade-offs
- SQL and NoSQL database design choices
- Search, object storage, and time-series data systems
- Distributed systems concepts such as scalability, replication, consistency, and partitioning

## Suggested learning order

1. Start with storage fundamentals.
2. Study relational databases and compare them with NoSQL families.
3. Move into search, object, and time-series storage.
4. Then continue into distributed systems design principles.

## Notes

This repository is intended as a study and reference guide for system design interviews, architecture exploration, and technical learning.
